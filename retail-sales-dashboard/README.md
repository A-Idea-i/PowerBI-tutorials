# Power BI for Beginners — 5-Session Video Series

Sample data and downloadable project files to follow along with the
Power BI for Beginners YouTube series.

## What's in this repo
- `data/RetailSales.xlsx` — the sample retail dataset used across all 5 sessions
  (Orders, Products, Customers)
- `session-files/` — the finished .pbix file from the end of each session,
  so you can jump in at any point

## Sessions
| Session | Topic | File |
|---|---|---|
| 1 | Getting Data In & Your First Dashboard | `RetailSalesDashboard_Session1.pbix` |
| 2 | Power Query & Data Modeling | `RetailSalesDashboard_Session2.pbix` |
| 3 | DAX Fundamentals | `RetailSalesDashboard_Session3.pbix` |
| 4 | Building the Dashboard | `RetailSalesDashboard_Session4.pbix` |
| 5 | Interactivity & Publishing | `RetailSalesDashboard_Session5.pbix` |

## How to use
1. Download `RetailSales.xlsx` from `/data`
2. Watch the session video for that week
3. Stuck? Download that session's `.pbix` from `/session-files` to compare
